Get Cohnsoft Game Producer

The full studio on your own computer: Forge can run Godot and Molder can run Blender right where your game lives. Your API key never leaves your machine.

Opening it the first time

macOS. Open the downloaded .dmg and drag the app to Applications. Builds that are not yet notarized by Apple are held by Gatekeeper after a download. Open System Settings → Privacy & Security, scroll down, and choose Open Anyway for Cohnsoft Game Producer. If macOS says the app is damaged, clear the download flag once in Terminal:

xattr -dr com.apple.quarantine "/Applications/Cohnsoft Game Producer.app"

Windows. If SmartScreen appears, choose More info → Run anyway. Linux. chmod +x AltStackGameProducer-linux-*.AppImage, then run it.

Verify a download: shasum -a 256 -c AltStackGameProducer-….sha256 (the checksum file is linked on each card).
